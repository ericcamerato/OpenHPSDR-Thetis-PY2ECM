THETIS PY2ECM 2.10.4.1 BETA 3 (x64)
==================================

Beta 3 is based on PY2ECM Beta 2. The only functional addition is NR7,
DeepFilterNet3 speech noise reduction for 48 kHz receive audio. It is
available in voice modes; CW, digital and FM bypass it. The NR7 settings
are in Setup > DSP > NR7. The default attenuation limit is 18 dB, and
the NR7-only output gain now defaults to +10 dB to compensate its lower
perceived loudness. Transmit processing and the default four-DDC
configuration are unchanged.

The optional one- and two-DDC modes inherited from Beta 2 are not
validated: the radio stopped after a short time in user testing. Use
the default four-DDC mode for normal operation.

No private Lextel/external-meter integration or personal settings are
included. The binary package contains the DeepFilterNet3 runtime, model,
and applicable license notices. The MSI and portable ZIP also include
the default skins and meter images. The MSI uses standard Windows desktop
and Start menu locations and does not launch graphical skin installers.
