THETIS PY2ECM 2.10.4.1 BETA 1 (x64)
==================================

This is a Windows x64 test release. The distributed executable is identical
to the locally approved 2.10.4.1 build from October 28, 2026 (SHA-256:
B5E7822436BABAC047A1B19B815B4F9F9766AA6B967B4A6050D6E8A70F5DDC84).
The MSI and portable packages contain no personal database, profiles,
memories, logs, machine-specific launch scripts, or author settings.

HIGHLIGHTS SINCE 2.10.3.16

- Redesigned 3D Panadapter and 3D Panafall with terrain, history, noise-floor
  contours, and signal colors. The RX filter overlay, data line, and visual
  options are integrated into the 3D modes.
- 3D Pan Classic and 3D PF Classic remain separate options preserving the
  geometry and appearance of the 2.10.3.16 rendering.
- The new 3D palette and contrast follow the 2D panadapter. The front ridge
  is more visible, while the background is balanced against the foreground.
- Fixed terrain alignment when changing panadapter levels, 3D fill after
  mode switches, and renderer initialization when opening or changing
  display modes.
- Reduced the gap between panadapter and waterfall in 3D Panafall.
- Added Ultrawide Mode in Setup > Display > General for ultrawide monitors
  at least 2560 pixels wide. The spectrum expands to both sides, while side
  controls move into an aligned bottom grid. Layout, mode controls, and
  slider positions remain consistent when switching layouts.
- The 2D waterfall and panadapter fill render on the GPU. The 2D trace uses
  a batched path for definition and lower CPU cost; a fully GPU-based
  2D trace is not the default.
- Added display-analyzer and WDSP optimization and profiling facilities.
  This release does not move the complete FFT or audio processing to the
  GPU: the audio path remains on the CPU.
- Display defaults are built into the application: high-definition 2D trace, GPU
  waterfall and fill, visible cmASIO configuration, enabled neural CW
  receive, and isolated PY2ECM-WDSP210 database identity. No environment
  variables or BAT file are needed to enable these features. Profiling
  and test controls are off by default.

INSTALLATION

- MSI: installs in its own folder without replacing the main Thetis
  installation or the local 2.10.4.1 build. It does not include a personal
  database. Requires .NET Framework 4.8 and the usual device drivers and
  runtimes for your radio and audio hardware.
- Portable ZIP: extract to its own folder and start Thetis.exe. The included
  user-data folder keeps settings beside the application.
- Do not run the MSI and portable copies with the same radio simultaneously.
  Before connecting or transmitting, check the device, audio, power,
  PA Gain, PureSignal, and other settings. Back up your database before
  importing settings from another installation.

VALIDATION AND LIMITATIONS

- The code compiled in Release x64. The MSI was built with WiX 3.14;
  real installation and radio RX/TX testing remain for QA.
- The MSI is not digitally signed and does not install external drivers.
- On some setups, NR6 and cmASIO with small blocks can cause clicks in
  monitored audio. Adjust Block Num to suit the device's stability; this
  alone does not establish a defect in the transmitted signal.
- CPU/GPU gains depend on resolution, frame rate, graphics hardware, and
  settings. No audio-latency improvement is guaranteed.
