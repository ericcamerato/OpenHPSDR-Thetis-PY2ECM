Thetis PY2ECM Beta 3 - Eric's local test package

Start with either:
  T:\PythonScripts\startThetisPY2ECM-Beta3-Full.bat
or the START-THETIS-BETA3-FULL.bat file in this folder.

Both launch the same executable and the same local user-data folder.
The user-data folder is a copy of the PY2ECM-WDSP210 test database, including
your CWX, DSP, display and radio settings as they stood on 2026-10-04.
The original database in AppData and the earlier Neural CW test folder are
not modified by these launchers.

The full launch flow preserves your previous options: high-performance power
plan during the session, high process priority, cmASIO configuration, neural
CW RX auto-enable, optional keyboard mute script, and cleanup at exit.

This folder contains personal radio settings. Do not publish or share it.
Use the separate Beta3-Portable ZIP if you want to send the program to others.
